Privacy Policy

pokeBot (Discord bot) · Last updated: August 12, 2026

pokeBot is a Pokémon-catching bot for Discord servers, run as a hobby project by one person. This page explains what the bot sees, what it keeps, and what you can do about it. I've tried to keep it specific rather than vague, because "we may collect certain information" tells you nothing.

pokeBot is not affiliated with Discord Inc., Nintendo, Game Freak, or The Pokémon Company. Using Discord itself is covered by Discord's Privacy Policy, not this one.

1. What the bot reads

pokeBot runs on Discord's Message Content intent. In plain terms: in servers it has been added to, and in channels where it has permission to read, it receives the text of messages sent by people. It needs this for two reasons and no others:

  • To recognize commands. Every command starts with a period, like .drop, .party, or .trade. The bot checks whether a message starts with one of those prefixes and ignores it if it doesn't.
  • To catch Pokémon. When a Pokémon is dropped in a channel, the bot compares the next messages against that Pokémon's name to see who typed it first.

Message text is checked in memory the moment it arrives and then dropped. It is not written to a database, not saved to a log file, and not read by me. Messages that aren't commands and don't match an active drop are discarded immediately.

The bot does not have Discord's direct message intent, so it cannot read your DMs at all, with me or with anyone else. It also does not read voice channels, attachments, or message history beyond what is posted while it is running.

2. What the bot stores

pokeBot keeps a small set of SQLite database files on the machine it runs on. Everything stored about you is tied to your Discord user ID, which is the number Discord assigns to your account. Here is the full list.

Your Discord user IDThe key for your save file. Nothing else identifies you.
Your caught Pokémon, including shiny status, form, and genderIt's the game.
Coins and gold balancesShop purchases and rewards.
Your item inventorySo items persist between sessions.
Totals: Pokémon caught, currency spentLeaderboards, quests, and achievements.

That's the whole thing. No email addresses, no IP addresses, no phone numbers, no location, no payment details, no message archives, no analytics events.

3. What only lives in memory

Some state is held in the bot's memory while it runs and is gone the moment it restarts: drop cooldown timers, whether you asked for a cooldown reminder with .remind, the Pokémon currently active in a channel, in-progress trades, and active repels.

4. Usernames and what other players can see

Your username and server nickname are not saved to the database. When a leaderboard is posted, the bot asks Discord for the current username attached to each user ID at that moment and shows it. If Discord doesn't return one, the raw user ID is shown instead.

Some commands are deliberately public, and you should know that going in. Anyone in a server with the bot can run .team @you to see your first six Pokémon, or .compare @you to list Pokémon you own that they don't. Your name and totals can appear on global and per-server leaderboards. If you'd rather not appear anywhere, the practical answer is not to play, since a save file is created the first time you catch something.

5. Who else gets your data

Nobody. Your data is not sold, rented, shared with advertisers, or handed to any analytics provider. There are no third-party services wired into the bot, no tracking pixels, and no ad network. Pokémon artwork is served from image links stored in the bot's own Pokémon database, so browsing the dex doesn't hand your activity to anyone either.

The only outside party involved is Discord, which necessarily carries every message the bot sends and receives.

6. Where it's kept and how it's protected

The database files sit on the server that runs the bot. They aren't published, exposed over a web address, or synced to a cloud service. Access is limited to me as the operator. I take reasonable care, but this is a hobby project rather than a bank, and I can't promise a system is beyond compromise. Please don't put anything sensitive into the bot, and remember that it stores game data only.

7. How long data is kept

Save files are kept for as long as the bot runs, so your collection is still there when you come back months later. There's no automatic expiry. Removing the bot from a server does not delete anyone's save data, since collections follow the user rather than the server.

8. Deleting your data

You can have your save file wiped at any time. Email wowniceblock@gmail.com from any address with your Discord user ID and ask for deletion. Sending the request from Discord itself is fine too. I'll remove your row from the user and quest databases, which deletes your Pokémon, currency, items, buffs, and quest progress permanently.

Two honest caveats. First, this is a manual process, so allow a few days rather than expecting it to be instant. Second, deletion can't be undone and Pokémon traded to other players stay with them, since those are now their Pokémon. You can also ask for a copy of what's stored about you, and I'll send back the contents of your row.

Server admins can clear the bot's channel settings for their server at any time with .resetChannels.

9. Children

pokeBot follows Discord's minimum age requirements and is not intended for children under 13, or under the higher minimum age in countries where that applies. If I learn that data belongs to a child below that age, I'll delete it.

10. Changes to this policy

If the bot starts collecting something new, this page gets updated and the date at the top changes with it. Meaningful changes will be noted in the support server where practical.

11. Contact

Questions, deletion requests, or anything that looks wrong on this page: wowniceblock@gmail.com.
